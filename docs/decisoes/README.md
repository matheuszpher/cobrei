# Decisões arquiteturais

Registro das decisões arquiteturais do Cobrei no formato ADR (Architecture Decision Record). Cada registro descreve o contexto, a decisão tomada, as alternativas consideradas e as consequências.

| [ADR-005](ADR-005-postgresql-prisma.md) | PostgreSQL e Prisma | Aceita | Equipe |
| [ADR-006](ADR-006-docker-compose.md) | Execução local com Docker Compose | Aceita | Equipe |
| [ADR-007](ADR-007-regra-de-envelhecimento-da-divida.md) | Regra de envelhecimento da dívida (aging) | Aceita | Equipe |

Novas decisões devem seguir a numeração sequencial. Uma decisão substituída não é apagada: o status passa para "Substituída por ADR-XXX".
